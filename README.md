# The Gerardo Guide

The website for thegerardoguide.com, built with Jekyll and hosted on GitHub Pages.

## Adding an article

1. Add a Markdown file to `_posts/` named `YYYY-MM-DD-short-name.md`.
2. Start it with this block, then write the article below it:

```
---
title: "Headline"
dek: "One-line summary under the headline"
description: "Same line, used for link previews"
place: "City, State"
permalink: /short-name/
---
```

3. Use `## Heading` for section heads.
4. Commit the file. The site updates in about a minute.

## Type

Iowan Old Style on Apple devices, Georgia elsewhere. Both are fonts already installed on readers' devices, so nothing loads from outside the site.
